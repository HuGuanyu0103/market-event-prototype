# 自选异动监测原型公开发布包

此目录已组装为 GitHub Pages 静态站点：`index.html` 是交互原型，`demo.html` 为同内容副本，`gallery.html` 为截图总览页，`assets/` 保存截图。站点无需构建或依赖安装。

**公开前请先确认授权。**原型页面展示合成的公司、ETF、行情、公告、持仓和财务情景，并含“腾讯自选股”产品名称与相似界面。请核对这些内容是否包含公司内部资料，是否有权将其公开到互联网；若不适合公开，请仅在内部分享。

压缩包只供审阅和用户自行发布。不要把真实凭证、内部资料或其他文件补入目录。公开页面任何人可访问，也可能被搜索引擎收录。评审结束后可删除公开仓库。

已创建空仓库：HuGuanyu0103/market-event-prototype。将本站点目录内容推送到该仓库的 main 分支后，在 GitHub Pages 设置中选择从 main 的根目录部署。
